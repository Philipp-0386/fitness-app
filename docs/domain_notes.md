# General Notes Regarding The Domai Of The Application

Overview of to be implemented features.

---

The application is a fitness app. In its final state, the software should support the following features:

- Core
  - Exercise catalog (lexicon, instructions, maybe GIFs?)
  - Custom exercise definition
  - Set tracker (reps, weight, RPE, rest)
  - Workout tracker (logging and saving of sessions)
  - Bodyweight tracker

- Routines
  - Workout templates
  - Weekly programm/schedule (multi-week plans)

- Analytics
  - Personal records
  - 1RM calculation/approximation (one rep max)
  - Volume and frequency display per muscle group
  - Historical progression per exercise (reps and weight)
  - Historical bodyweight progression
